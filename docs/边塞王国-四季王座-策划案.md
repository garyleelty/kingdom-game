## 1. 简介

**核心提炼**：一局 30 季的回合制小王国生存。玩家经营「金币—粮食—木材—石料」四资源循环，在**马匪威胁逐季成长**的压力下，抢在时限前建成「王座奇观」。

**要解决的问题 / 期望效果**：
- 用**单局 15–20 分钟**的轻量玩法，承担主线之间的节奏调剂；
- 用"资源流通取舍"而非数值堆料制造重开动力，**几乎零美术成本**复用现有建筑/资源素材；
- 为数值组提供一个**可完全用脚本模拟**的验证场（本玩法所有规则均为纯函数，已实测 300 局自动对弈调平）。

**体验流程一句话**：开局缺钱不缺粮 → 中期发现木/石堆积、金币永远不够 → 学会「卖多余建材换金」的集市循环 → 后期一边补城防挡马匪、一边凑奇观三件套 → 第 21 季前后惊险落成（或王朝谢幕）。

## 2. 实现目标

| 面向 | 目标 | 手段 |
|---|---|---|
| **制作人** | 预期小幅提升次日留存（轻量单局玩法填充碎片时间），对单日收益无直接影响 | 单局时长可控（30 季上限）、失败可立即重开 |
| **主策** | 提供"经济压力曲线"标准样板：前期宽松、中期死锁风险、后期威胁成长 | 三档税制 + 集市额度 + 成长型马匪，三个压力阀独立可调 |
| **其他系统** | 与主线科技树解耦，无共享资源池，不产生跨系统通胀 | 全部资源为局内临时资源，局末清零 |
| **数值** | 全规则纯函数化，支持脚本批量模拟 | `js/game.js` 无 DOM 依赖 + 可复现随机种子（mulberry32） |
| **剧情** | 事件文案承载世界观（马匪、流民、商队），不改动现有设定 | 事件池独立配置表，文案与逻辑解耦 |
| **甲方/外包** | 前端零依赖零构建，验收即开浏览器 | 单 HTML + 原生 JS |

**体验规划**：首局教学靠界面目标提示（🎯 常驻底栏）完成，不做强制引导；目标胜率设计为「新手 1 局摸到门道，3–5 局稳定通关」。

## 3. 基础设定

### 3.1 资源定义（均为局内资源，局末清零）

| 资源 | 获取 | 消耗 | 定位 |
|---|---|---|---|
| 🪙 金币 | 市场产出、人口税收、商队事件、**集市卖出建材** | 几乎所有建筑造价、庆典、募兵、买建材 | **稀缺瓶颈资源**（本玩法核心张力来源） |
| 🌾 粮食 | 农田、丰收事件 | 人口口粮（0.9/人/季）、兵营 upkeep | 生存线，为负触发饥荒 |
| 🪵 木材 | 伐木场、集市买入 | 农田/采石场/市场/民居/奇观 | 过剩型资源，鼓励向金币转化 |
| 🪨 石料 | 采石场、集市买入 | 兵营/城墙/神庙/奇观 | 同木材 |

### 3.2 建筑表（配置即数据，见 `BUILDINGS`）

| 建筑 | 造价 | 每季效果 |
|---|---|---|
| 农田 | 60🪙 20🪵 | +12🌾 |
| 伐木场 | 55🪙 | +12🪵 |
| 采石场 | 70🪙 15🪵 | +10🪨 |
| 市场 | 80🪙 20🪵 | +20🪙 |
| 兵营 | 100🪙 30🪨 | +4⚔️， upkeep 6🌾 |
| 城墙 | 80🪙 40🪨 | 防御 +15（可叠加） |
| 民居 | 40🪙 20🪵 | 人口上限 +20，+3🪙 |
| 神庙 | 120🪙 50🪨 | +3 忠诚 |
| **王座奇观** | **350🪙 120🪵 120🪨** | **建成即胜利（限 1 座）** |

### 3.3 状态量

- **人口**：起始 40，上限 = 40 + 民居×20；忠诚 ≥50 且粮 >30 时每季 +2；饥荒/暴政流失。
- **忠诚 0–100**：起始 60。≥70 民心归附，<30 濒临暴动，**归零判负**。
- **军队**：起始 10；兵营训练、募兵（30🪙→+5）、佣兵事件。
- **总防御** = 城墙×15 + 军队×1.2。

### 3.4 税制（三档，随时可切）

| 档位 | 税收系数 | 每季忠诚 |
|---|---|---|
| 轻税 | ×0.6 | +2 |
| 中税 | ×1.0 | 0 |
| 重税 | ×1.5 | −4 |

### 3.5 集市兑换（本玩法的关键安全阀）

| 商品 | 批量 | 买入价 | 卖出价 |
|---|---|---|---|
| 木材 | 10 | 3🪙/单位 | 2🪙/单位 |
| 石料 | 10 | 4🪙/单位 | 2🪙/单位 |
| 粮食 | 20 | 2🪙/单位 | 1🪙/单位 |

- 每季限 **3 单**，季初刷新；买卖价差 + 额度双防套利；卖粮不可断口粮。
- **设计动机（v0.6 补丁）**：实现验证中发现，若建材可被耗光而所有生产建筑造价又含建材，会出现**永久死锁**（实测木材归零后金币停滞 24 季）。集市给玩家一条"用过剩资源买回产能"的通路，同时天然形成进阶技巧（卖木换金冲奇观，实测胜率 33%→98%）。

### 3.6 与其他系统关联 / 配置需求

- 新增配置表 4 张：建筑表、税制表、事件池表、集市价格表——**均为纯数据 JSON 可外置**；
- 事件池 10 条（瘟疫/马匪/丰收/商队/流民/大旱/庆典/苛政/地震/佣兵），带权重，逻辑以回调挂载，程序侧可改为指令码；
- 无跨系统引用，无新增账号级货币。

### 4.2 关键交互规则

| 编号 | 规则 |
|---|---|
| I-1 | 建筑卡资源不足时**置灰不可点**，缺项造价文字标红（`.lack`） |
| I-2 | 一切操作（建造/税制/集市/庆典/募兵）**不限次数、即时生效**，仅受资源与集市额度约束；「结束本季」是唯一推进时间的按钮 |
| I-3 | 马匪威胁 ≥ 我方防御时顶栏威胁文字**标红**，否则灰色；T8 前不显示 |
| I-4 | 操作失败不弹窗，在「本季事件」框内以 ⚠ 前缀提示原因（复用面板，减少层级） |
| I-5 | 胜负触发时盖半透明结算层：标题（🏆/💀）+ 结局文案 + 成绩摘要（历经 N 季/人口/忠诚）+ 再开一局 |

## 5. 规则逻辑

### 5.1 层次结构（思维导图）

```
四季王座
├─ 玩家操作（季内自由，不推进时间）
│   ├─ 建造 BUILDINGS
│   ├─ 税制切换 TAX_LEVELS
│   ├─ 集市买卖（额度 tradeLeft=3/季）
│   ├─ 庆典（50🪙→忠诚+10）/ 募兵（30🪙→军+5）
│   └─ 结束本季 → 进入结算
├─ 季度结算（endTurn，固定 6 步，顺序即优先级）
│   ├─ ① 收支：Σ建筑产出 + 税收 − 口粮(人口×0.9) − 兵营 upkeep
│   ├─ ② 税制忠诚修正
│   ├─ ③ 饥荒判定：粮<0 → 按缺口折人口，忠诚−8，粮清零
│   ├─ ④ 人口增减：忠诚≥50 且粮>30 → +2（不超上限）；忠诚<25 → −3
│   ├─ ⑤ 随机事件：70% 触发，按权重抽取
│   └─  胜负判定（见 5.3）→ 未结束则 turn+1，集市额度刷新
└─ 单局生命周期：newState → 循环(操作+endTurn) → 结算层
```

### 5.2 马匪结算公式（事件 `raiders`）

```
威胁值 threat = turn < 8 ? 0 : min(80, 15 + (turn−7)×4)
防御值 defense = 城墙×15 + 军队×1.2
若 defense ≥ threat：无损失，播报"抵御成功"
否则缺口率 gap = (threat − defense) / threat：
    损失金币 = min(当前金币, 25 + 65×gap)
    损失军队 = min(当前军队, 3 + 9×gap)
    忠诚 −4
```
设计意图：T8 前教学窗口；T8–20 一次城墙/两波募兵可稳；T20+ 威胁封顶 80，防止后期无解滚雪球。

### 5.3 胜负判定（每季结算第⑥步，按序短路）

| 优先级 | 条件 | 结果 |
|---|---|---|
| 1 | 奇观建成（操作时立即判定） | **胜**（建造胜利，主目标） |
| 2 | 人口 ≤ 0 | 败 · 王国覆灭 |
| 3 | 忠诚 ≤ 0 | 败 · 革命倾覆 |
| 4 | 第 30 季结束仍未成奇观 | 败 · 王朝谢幕 |

### 5.4 细节规则备忘（程序/测试向）

- 随机数：mulberry32，种子入档 → **同种子全流程可复现**（冒烟测试第 7 项已覆盖）；
- 忠诚钳制 [0,100]；金币/粮/木/石允许大额囤积但不为负（卖粮有生存线保护）；
- 奇观全局唯一，重复建造返回"奇观已建成"；
- 地震事件不毁奇观（保护胜利进度）；无建筑时地震仅播报不惩罚；
- 事件回调注入 helpers（`totalDefense/popCap/destroyRandomBuilding/raiderThreat`），配置表外置时改为指令码分发。

## 7. 附录：数值验证报告

验证工具：`test/smoke.test.js`（8 项规则断言）+ `test/sim.js`（策略批量对弈），命令 `node test/smoke.test.js && node test/sim.js`。

| 打法 | 300 局胜率 | 中位通关季 |
|---|---|---|
| 无为（不操作） | 0% | — |
| 只会造田（不懂集市、不管防务） | 0% | — |
| 只买不卖（用集市补缺但不卖 surplus） | ~33% | ~29（惊险） |
| 合格打法（税制 + 防务 + 集市套利冲奇观） | 98% | 21 |

结论：目标可达、有明确失败面、存在"理解集市"这一核心技巧门槛，符合休闲策略定位。威胁成长与死锁修复两项关键改动均由模拟数据驱动发现。
