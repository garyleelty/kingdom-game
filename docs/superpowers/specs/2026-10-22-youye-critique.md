## ROUND 1

Seen in one second: 一张宣纸色的路，一条八段路的行程，右边一栏随身之物，底下压着一幅钟馗夜行图。
Idea: 打出的牌变成战阵；同名牌之间落一道金印。
Live thing: 点手牌，牌飞进战阵。
Layout words by section: 顶栏=产品印记与本局状态 / 标题行=遭遇名与那一句发现 / 左栏=战阵与手牌 / 右栏=对手、我方、牌堆、日志 / 底=钟馗夜游图
Scores: design 7 · usability 6 · creativity 7 · content 7 → overall 6.8
Caps applied: 不用「英雄头图」，界面元素不进 chrome，卡牌是数据不是装饰。

Top three problems (most visible first):
1. **前版根本没有这些屏**。异闻、战利品、篝火三块 HTML 一直存在，JS 却从不显示它们——地图压在前面，玩家永远看不到异闻选项、看不到战利品、碰不到篝火。修：先决定"当前该显示哪一屏"，再各自渲染。
2. **侧栏的数字和标签隔了 287px**。`justify-content: space-between` 把 320px 宽的侧栏拉满，一个两字标签和它的数字被甩到两端；30px 的气势值又靠左，其余数字靠右，读起来像两张不相干的表。修：键值成一张紧的小表（标签 72px + 数值 60px 右对齐），气势值与它同侧。
3. **地图那幅画和它的说明对不上**。4.8:1 的裁切把《钟馗夜游图》切成几张断掉的脸，底下却写着"夜色中的山道"。修：改裁切（带上伞与山路），图注改说画里真正有的东西。

另外查出的坏东西：事件选项写成"−-10 血"（负号重复）；战斗日志里混进一个 🔗；认不出的牌 id 会渲染成一张空白卡；画像每次重绘都闪一下空白（`<img>` 每次重建）；篝火面板是死代码；手机上手牌露出一根丑陋的滚动条；手机上路的状态字掉到第二行读起来像名字的一部分；卡面"同名牌连发"被从中间折成"同名/牌连发"。

## ROUND 2（终轮）

Seen in one second: 宣纸上一条路，路的尽头压着一幅有人举着伞的夜行图。
Idea: 打出的牌变成战阵；同名牌之间落一道金印。
Live thing: 点手牌，牌从手牌飞进战阵，同名牌落下时两牌之间生成金印。
Layout words by section: 顶栏=印记与本局三数 / 标题行=遭遇名与气势发现 / 左栏=战阵(带金印)与手牌 / 右栏=对手画像、我方、牌堆、日志，全部靠左读 / 底=钟馗夜游图 + 出处
Scores: design 8 · usability 8 · creativity 8 · content 7 → overall 7.8
Caps applied: 不加英雄头图；界面元素不进 chrome；卡牌是数据；图像是主体自己的世界，不冒充游戏资产。

Top three problems (most visible first):
1. **战阵右侧空着一大块**（battle-1440：战阵止于 x=410，右边空到 950）。这是游戏盘面，不是内容页——牌会一张张落上去，空着是对的；但手牌最多 6 张时它会填满左栏，所以这一块按"会填满"处理。
2. **战阵与手牌不像一套东西**（battle-1440：未连发的已出牌与手牌像素相同，只有连发那张变金）。金就同时表示"已连发"和"值得注意"，两件事挤在一个信号上。修：连发牌改用压金纹的纸 + 金印连接 + 角标 ×2，三重信号，不靠颜色单打。
3. **手机上手牌第四张被切成半个字**（battle-390：最右文字出界 23px）。没有滚动条提示了。修：隐藏滚动条，靠被裁掉的卡边作提示；卡片缩到 96px 并把说明拆成短段，保证没有任何字被挤出卡面（已量：0 处溢出）。

终轮量到的数：字号 13/14/15/17/24（五档，正好到顶）；字体两族；chrome 无色，只有三个矿物色相；
lint 0 FAIL / 0 WARN；inspect 0 FAIL / 0 WARN（1440 / 768 / 390）；外边距左右相等（160/160、32/32、16/16）；
横向溢出 0；控制台错误 0。
