# 《幽夜行》设计文档

日期：2026-10-17
状态：待用户复审
范围：小体量试玩版（东方志怪 + 卡牌构筑 Roguelike，纯前端本地即玩）

---

## 1. 概述

你是落魄的阴阳师/剑客，在妖雾漫过山门的最后一夜，一路向上，斩开一条生路。

- 单局目标：**40 分钟左右**，6 张地图节点选路，8–10 场战斗、4–5 个事件、1 个 Boss。
- 单局模式：卡牌构筑 Roguelike。死亡即本局结束，保留"解锁"进度（试玩版只做 1 名主角，不做进阶等级）。
- 与《边塞王国》区别：经营生存 → 构筑成长。单局短、重开快、随机性强。

**不做什么（YAGNI）**：不做联机、不做多主角、不做每日挑战、不做跨会话存档续局（局内状态仅存内存，关闭页面即重开）。

---

## 2. 战斗规则

### 2.1 回合流程

1. **开局**：抽满 5 张手牌，灵气回满 3 点；
2. **意图显示**：敌人头顶明示本回合动作（如「⚔ 8」「🛡 5」）；
3. **玩家出牌**：点击打出，消耗灵气，效果立即生效；每回合可弃牌一次（弃掉不要的牌换抽新牌）；
4. **结束回合**：敌人按意图行动；
5. 循环至一方血量 ≤ 0。

### 2.2 核心资源

| 资源 | 来源 | 用途 |
|---|---|---|
| 灵气（能量） | 每回合 +3 | 打牌消耗（每张 0–2 点） |
| 气势 | 打出攻击牌 +2 | 满 6 点触发大招「一剑霜寒」三连击 12 伤害，跨回合保留 |
| 格挡 | 防御牌获得 | 抵挡本回合敌人伤害，回合结束清零 |
| 血量 | — | 归零本局结束 |

### 2.3 卡牌三类型

- **攻击**（红/朱砂）：伤害 + 积气势；
- **技能**（蓝/黛青）：格挡、抽牌、减意图；
- **能力**（金/赭金）：打出后留在战场，每回合自动触发。

### 2.4 难度手感

普通敌人伤害 4–12，普通战斗 6–10 回合结束；Boss 血量降到 50% 解锁新意图（阶段变身），作为一局的高潮。

## 3. 地图、事件与遗物

### 3.1 地图结构（单线带分支）

```
起 → 战斗 → ? 事件 → 战斗 → 精英/Boss → 战斗 → Boss → 终
```

- ⚔️ **战斗**：普通敌人，掉落金币 + 卡牌奖励（3 选 1）；
- ❓ **事件**：志怪小故事，2–3 个选项；
- 💀 **精英/Boss**：强敌，更多金币 + 必得遗物；最终 Boss 难度最高。

### 3.2 卡牌构筑

- 胜利后从 3 张候选选 1 加入牌组；
- 同名牌可叠，每叠一张效果 +50%；
- 12 张基础卡 + 20 张升级卡 = 32 张卡池。

### 3.3 遗物（本局被动）8 个

1. 铜钱串：每场战斗开局 +5 金币；
2. 断剑穗：攻击牌气势 +1；
3. 罗盘碎片：每 3 回合抽 1 张额外牌；
4. 旧灯笼：第一场战斗敌人伤害 −3；
5. 符纸囊：战斗胜利后回 5 血；
6. 半卷妖经：能力牌费用 −1（最低 0）；
7. 夜行披风：每回合首张格挡牌效果 +2；
8. 破山令：大招伤害 12 → 16。

### 3.4 事件示例（3 个）

1. 荒庙遇无面人：给 1 金币 → 得遗物；拒绝 → 无事；
2. 夜雨古井：下井 −10 血 + 得 2 张随机卡；不下 → 路过；
3. 茶棚老妪：喝茶 −15 金 → 回 15 血。

### 3.5 金币消费

小体量只做「战斗后回血点」（−50 金 → 回 20 血）一个出口，避免复杂商店，后续可扩展。

## 4. 实现架构

### 4.1 技术选型

纯 HTML + CSS + 原生 JS，零依赖零构建，浏览器打开 `index.html` 即玩。核心逻辑抽成无 DOM 纯函数模块，Node 可直接跑测试。

### 4.2 文件结构

```
youye/
  index.html         入口（水墨宣纸页面）
  css/style.css      水墨视觉规范
  js/cards.js        卡牌数据表（32 张）+ 敌人表 + 遗物表 + 事件表
  js/engine.js       战斗引擎（纯逻辑：抽牌/出牌/格挡/气势/意图结算）
  js/run.js          单局流程（地图选路/事件/战斗衔接/奖励三选一）
  js/ui.js           渲染与交互（牌桌、意图条、地图、事件面板、结算层）
  test/engine.test.js 战斗引擎规则测试
  test/run.test.js   单局流程冒烟测试
```

### 4.3 模块边界

- `engine.js` 只管一场战斗的回合结算：输入状态、输出新状态 + 事件日志；不碰 DOM、不碰随机种子之外的世界状态。
- `run.js` 管地图选路、事件结果、卡牌奖励、遗物装配，调用 engine 完成战斗。
- `ui.js` 只管渲染与点击转发，不写规则。

## 5. 视觉规范（水墨宣纸）

- 底色：米白宣纸 `#e8e0cc` + 局部墨渍渐变；
- 文字：墨黑 `#1a1a1a`；强调色朱砂红 `#a8301f`（血量/攻击牌/气势满）、黛青 `#2f4858`（技能牌/灵气）、赭金 `#8a6d2f`（能力牌/遗物）；
- 卡牌：竖版木牌，朱砂印章式角标显示费用，毛笔字标题（楷体/宋体系统字体回退，不加载外部字体）；
- 敌人意图：头顶图标 + 数字，朱砂表攻击、黛青表防御；
- 过渡：纯 CSS 淡入淡出 + 墨渍扩散，无动画库。

## 6. 测试策略

- **引擎测试**覆盖：抽牌上限、弃牌、格挡回合清零、气势累积与三连击结算、敌人意图结算、能力牌持续触发、胜负判定；
- **流程测试**：固定随机种子跑通完整一局（战斗 → 事件 → Boss → 结算），保证可达终局。

---

## 7. 验收标准

- 浏览器打开 `index.html` 能开始一局，完整流程可打通至结算界面；
- `node test/engine.test.js`、`node test/run.test.js` 全部通过；
- 同种子流程可复现（冒烟测试覆盖）；
- 单局实际时长 ≤ 45 分钟，普通战斗 ≤ 10 回合。
