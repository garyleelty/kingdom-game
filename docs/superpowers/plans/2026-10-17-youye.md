# 《幽夜行》Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现本地可玩的东方志怪卡牌构筑 Roguelike《幽夜行》小体量试玩版。

**Architecture:** 纯前端，零依赖零构建。核心逻辑抽成无 DOM 纯函数模块（engine.js / run.js / cards.js），Node 可直跑测试；UI 只负责渲染与点击转发。

**Tech Stack:** 原生 JavaScript（Node v26 兼容）+ 原生 HTML/CSS + Node `assert` 做测试。

---

## 文件结构

```
youye/
  index.html           入口页面（水墨宣纸）
  css/style.css        水墨视觉规范
  js/cards.js          卡牌/敌人/遗物/事件 数据表（纯数据，UMD）
  js/engine.js         战斗引擎（纯逻辑，UMD）
  js/run.js            单局流程（地图/事件/战斗衔接/奖励，UMD）
  js/ui.js             渲染与交互
  test/cards.test.js   数据表完整性测试
  test/engine.test.js  战斗引擎测试
  test/run.test.js     单局流程冒烟测试
  test/sim.js          平衡模拟
```

## Task 1: 数据表 `js/cards.js`

**Files:**
- Create: `youye/js/cards.js`
- Create: `youye/test/cards.test.js`

- [ ] **Step 1: 写失败测试（数据表完整性）**

```javascript
// test/cards.test.js
const assert = require("assert");
const { CARDS, ENEMIES, ELITES, BOSS, RELICS, EVENTS } = require("../js/cards.js");

assert.strictEqual(Object.keys(CARDS).length, 32, "应正好 32 张卡");
assert.strictEqual(Object.values(CARDS).filter(c => c.tier === "base").length, 12);
assert.strictEqual(Object.values(CARDS).filter(c => c.tier === "upgrade").length, 20);
assert.strictEqual(Object.keys(ENEMIES).length, 8, "普通敌人 8 种");
assert.strictEqual(Object.keys(ELITES).length, 2, "精英 2 种");
assert.ok(BOSS, "应有最终 Boss");
assert.strictEqual(Object.keys(RELICS).length, 8, "遗物 8 个");
assert.strictEqual(Object.keys(EVENTS).length, 6, "事件 6 个");
for (const [id, c] of Object.entries(CARDS)) {
  assert.ok(["attack","skill","power"].includes(c.type), `${id} 类型非法`);
  assert.ok(c.cost >= 0 && c.cost <= 3, `${id} 费用非法`);
}
console.log("cards.test OK");
```

- [ ] **Step 3: 实现 `js/cards.js`**（完整数据，含 UMD）
- [ ] **Step 4: 运行确认通过**
